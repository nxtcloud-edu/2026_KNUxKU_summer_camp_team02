# Alongside 랜딩페이지 제작 요청

AI 스터디 메이트 서비스 **Alongside**의 랜딩페이지를 만들어줘.

전체적인 스타일은 **simple, soft, clean, calm​**한 느낌으로 구성하고, 너무 많은 정보나 장식을 넣지 않은 **한 화면 중심의 Hero Landing Page**로 만들어줘.

이 페이지에서 가장 중요한 것은 첫 화면만 보고도 사용자가

**“여러 AI 캐릭터와 한 공간에서 함께 공부하는 서비스”**

라는 점을 이해할 수 있게 하는 것이다.

---

# 1. 전체 페이지 구조

페이지는 화면 전체를 사용하는 **좌우 2단 레이아웃**으로 구성한다.

```text
┌───────────────────────────────────────────────────────────────┐
│                                                               │
│                                                               │
│      ┌──────────────────┐          Alongside                  │
│      │                  │                                     │
│      │   AI     AI      │          Study alongside AI         │
│      │                  │          companions who keep         │
│      │                  │          you focused.                │
│      │   AI     AI      │                                     │
│      │                  │          [ Sign Up ] [ Sign In ]     │
│      └──────────────────┘                                     │
│                                                               │
│                                                               │
└───────────────────────────────────────────────────────────────┘
```

화면을 크게

- **왼쪽: AI 캐릭터 스터디룸**
- **오른쪽: 브랜드 및 시작 영역**

으로 구분한다.

두 영역 사이에는 충분한 여백을 두어 답답하지 않도록 한다.

---

# 2. 왼쪽 영역 — AI 스터디룸

왼쪽 영역에는 페이지에서 가장 큰 시각적 요소인 **스터디룸 화면**을 배치한다.

구글 미트의 여러 참가자 화면처럼 보이는 구조를 참고하되, 실제 화상회의 서비스 UI처럼 복잡하게 만들지는 않는다.

큰 하나의 rounded container 안에 **4개의 참가자 화면을 2 × 2 형태**로 배치한다.

구조는 다음과 같다.

```text
┌─────────────────────────────┐
│                             │
│    ┌────────┐ ┌────────┐    │
│    │        │ │        │    │
│    │  AI 1  │ │  AI 2  │    │
│    │        │ │        │    │
│    └────────┘ └────────┘    │
│                             │
│    ┌────────┐ ┌────────┐    │
│    │        │ │        │    │
│    │  AI 3  │ │  AI 4  │    │
│    │        │ │        │    │
│    └────────┘ └────────┘    │
│                             │
└─────────────────────────────┘
```

각 화면에는 **AI 스터디 메이트 캐릭터 한 명씩** 들어간다.

---

# 3. AI 캐릭터 표현

캐릭터들은 단순한 프로필 이미지처럼 배치하는 것이 아니라,

**각자 자기 자리에서 공부하고 있는 사람처럼 보여야 한다.**

예를 들면 다음과 같은 모습이다.

- 책을 읽고 있는 캐릭터
- 노트북을 보고 있는 캐릭터
- 필기를 하고 있는 캐릭터
- 잠시 생각하거나 쉬고 있는 캐릭터

4명의 캐릭터는 동일한 모습이 아니라 조금씩 다른 행동을 하고 있어야 한다.

이를 통해 사용자가 별도의 설명을 읽지 않아도

**“여러 스터디원이 각자 공부하고 있는 방”**

이라는 느낌을 받을 수 있도록 한다.

캐릭터는 실제 사람 사진이 아니라 **깔끔하고 귀여운 일러스트 캐릭터**를 사용한다.

너무 어린이용 캐릭터처럼 보이지 않도록 하고, 대학생이나 성인이 사용하는 서비스에도 자연스럽게 어울리는 형태로 만든다.

---

# 4. 스터디룸 UI에서 제외할 요소

이 영역의 목적은 화상회의 기능을 보여주는 것이 아니라

**AI 캐릭터들이 함께 공부하고 있다는 존재감**을 보여주는 것이다.

따라서 초기 랜딩페이지에서는 다음 요소를 과도하게 넣지 않는다.

- 마이크 버튼
- 카메라 버튼
- 화면 공유 버튼
- 통화 종료 버튼
- 복잡한 메뉴
- 참가자 관리 UI
- 채팅창
- 설정 메뉴

이러한 기능 UI보다는 **4명의 AI 캐릭터 자체가 중심**이 되어야 한다.

구글 미트의 인터페이스를 복제하는 것이 아니라,

**“같은 방에 여러 존재가 함께 있는 화면 구조”만 참고한다.**

---

# 5. 오른쪽 영역 — 브랜드 영역

오른쪽에는 다음 세 가지 요소를 배치한다.

```text
Alongside

Study alongside AI companions
who keep you focused.

[ Sign Up ]   [ Sign In ]
```

요소의 중요도는

**브랜드 이름 → 설명 → CTA**

순서로 명확하게 보이도록 한다.

---

# 6. 브랜드 이름

서비스 이름은

# Alongside

이다.

브랜드명은 페이지 오른쪽 영역에서 가장 크고 눈에 띄는 텍스트로 배치한다.

참고 이미지의 **Mina 로고처럼 단순한 wordmark 형태**를 사용한다.

폰트는 다음 특성을 가지면 좋다.

- 깔끔함
- 약간 귀여운 느낌
- 부드러운 형태
- 지나치게 장식적이지 않음
- 높은 가독성

완전한 손글씨보다는 **깔끔한 rounded sans-serif 또는 부드러운 sans-serif**가 더 적절하다.

`Alongside` 전체가 하나의 로고처럼 보이도록 한다.

단, **A와 L 글자를 나머지 글자와 시각적으로 살짝 구분**하여 작은 브랜드 포인트를 만든다.

텍스트 크기나 폰트 스타일 자체를 크게 바꾸지는 말고 하나의 단어처럼 자연스럽게 유지한다.

필요하다면 브랜드명 왼쪽에 아주 작은 **sparkle 형태의 심볼**을 사용할 수 있다.

단, 심볼보다 Alongside라는 이름이 중심이어야 한다.

---

# 7. 브랜드 설명

브랜드 이름 바로 아래에는 한 줄짜리 짧은 설명을 배치한다.

사용할 문구:

**Study alongside AI companions who keep you focused.**

이 문구의 목적은 기능을 자세히 설명하는 것이 아니라

**Alongside가 어떤 서비스인지 한 문장으로 이해시키는 것**이다.

브랜드명보다 훨씬 작은 크기로 사용하고, 얇고 깔끔한 글씨체를 사용한다.

브랜드명과 설명 사이에는 적당한 여백을 둔다.

---

# 8. Sign Up / Sign In 영역

브랜드 설명 아래에는 서비스 진입을 위한 두 개의 버튼을 배치한다.

```text
[ Sign Up ]    [ Sign In ]
```

두 버튼은 **가로로 나란히 배치한다.**

### Sign Up

새로운 사용자를 위한 주요 CTA이다.

두 버튼 중 조금 더 눈에 띄도록 구성한다.

버튼 텍스트는 정확하게

**Sign Up**

으로 표시한다.

### Sign In

기존 사용자를 위한 버튼이다.

Sign Up 옆에 같은 크기 또는 유사한 크기로 배치한다.

버튼 텍스트는

**Sign In**

으로 표시한다.

### 버튼 클릭 동작

현재 MVP에서는 **Google 로그인만 제공한다.**

따라서 Sign Up과 Sign In은 서로 다른 가입/로그인 페이지로 이동하지 않는다.

두 버튼 모두 클릭 시 **현재 랜딩페이지 위에 동일한 로그인 오버레이(modal)** 를 연다.

즉, 사용자에게는 Sign Up / Sign In을 구분해서 보여주되 실제 인증 흐름은 하나로 통합한다.

- 기존 Google 계정 사용자 → 로그인 처리
- 처음 사용하는 Google 계정 → 계정 생성 후 로그인 처리

별도의 이메일 입력창, 비밀번호 입력창, 회원가입 폼은 만들지 않는다.

---

# 9. 버튼 스타일

두 버튼 모두

- rounded rectangle 형태
- 충분한 내부 여백
- 깔끔한 형태
- 약간 굵은 글씨
- 지나치게 큰 크기는 사용하지 않음

으로 만든다.

버튼의 border radius는 페이지의 다른 카드 및 스터디룸 모서리와 자연스럽게 맞춘다.

버튼에 긴 설명이나 불필요한 아이콘은 넣지 않는다.

Sign Up과 Sign In은 스타일상 구분할 수 있지만, **둘 다 동일한 Google 로그인 modal을 여는 진입 버튼**이다.

---

# 10. 로그인 오버레이(modal)

Sign Up 또는 Sign In 버튼을 클릭하면 **별도의 로그인 페이지로 이동하지 않고**, 현재 랜딩페이지 위에 로그인 modal을 띄운다.

로그인 modal이 열렸을 때는 뒤쪽의 랜딩페이지가 그대로 남아 있어야 한다.

즉, 사용자가 Alongside의 브랜드와 AI 스터디룸 비주얼을 본 상태에서 자연스럽게 로그인할 수 있도록 한다.

구조 예시는 다음과 같다.

```text
┌──────────────────────────────┐
│                          ×   │
│                              │
│          Alongside           │
│                              │
│    Ready to study together?  │
│                              │
│  [ G  Continue with Google ] │
│                              │
│      Terms · Privacy         │
│                              │
└──────────────────────────────┘
```

### modal에 포함할 요소

1. **닫기 버튼**
   - 오른쪽 상단에 `×` 형태로 배치
   - 클릭 시 다시 랜딩페이지로 돌아감

2. **Alongside 브랜드명**
   - modal 상단에 간단하게 표시

3. **짧은 안내 문구**
   - 예시: **Ready to study together?**

4. **Google 로그인 버튼**
   - modal에서 가장 중요한 CTA
   - 버튼 텍스트는 **Continue with Google**
   - Google 로고 아이콘을 버튼 왼쪽에 배치해도 됨

5. **Terms / Privacy**
   - modal 하단에 작게 배치
   - Google 로그인 버튼보다 시각적으로 훨씬 덜 강조

### modal에서 제외할 요소

현재 MVP에서는 Google 인증만 사용하므로 다음 요소는 만들지 않는다.

- 이메일 입력창
- 비밀번호 입력창
- 비밀번호 확인
- 이름 입력
- 회원가입 폼
- Sign Up / Sign In 탭
- 다른 소셜 로그인 옵션

로그인 modal은 **최소한의 요소만 있는 매우 단순한 구조**로 만든다.

### 로그인 흐름

```text
Landing Page
    ↓
Sign Up 또는 Sign In 클릭
    ↓
Login Modal
    ↓
Continue with Google
    ↓
Google OAuth
    ↓
기존 사용자 → Study Room
신규 사용자 → 필요한 경우 간단한 초기 설정 → Study Room
```

신규 사용자와 기존 사용자를 구분하기 위해 별도의 로그인 화면을 만들 필요는 없다.
Google 인증 결과를 기준으로 시스템에서 자동으로 처리한다.

---

# 11. 오른쪽 영역의 수직 구조

오른쪽 영역은 다음 순서를 명확하게 유지한다.

```text
        Alongside
            ↓
      브랜드 설명 한 줄
            ↓
     Sign Up / Sign In
```

각 요소 사이에는 충분한 여백을 둔다.

모든 콘텐츠를 화면 정중앙에 몰아넣기보다는 페이지 전체 균형을 고려하여 **오른쪽 영역의 중앙 부근**에 자연스럽게 배치한다.

---

# 12. 여백과 밀도

이 랜딩페이지에서는 **여백이 매우 중요하다.**

정보를 많이 보여주는 페이지가 아니라 첫인상을 만드는 페이지이므로 화면을 꽉 채우려고 하지 않는다.

다음 원칙을 따른다.

- 페이지 바깥 여백을 충분히 확보한다.
- 좌우 영역 사이를 충분히 띄운다.
- 브랜드명과 설명 사이에 공간을 둔다.
- 설명과 버튼 사이에도 충분한 공간을 둔다.
- 스터디룸 내부의 4개 캐릭터 화면 사이에도 일정한 간격을 둔다.

전체적으로 **숨 쉴 공간이 있는 디자인**으로 만든다.

---

# 13. 모서리 형태

페이지 안의 주요 UI 요소는 직각보다 **rounded corner**를 사용한다.

특히

- 스터디룸 외부 container
- 캐릭터 화면 4개
- Sign Up 버튼
- Sign In 버튼

에 동일한 디자인 언어를 적용한다.

단, 모든 요소를 지나치게 동글동글하게 만들어 어린이 서비스처럼 보이지 않도록 한다.

---

# 14. 랜딩페이지에서 전달해야 할 서비스 개념

Alongside는 일반적인 화상회의 서비스가 아니다.

또한 단순히 AI에게 질문하는 AI Tutor 서비스도 아니다.

핵심 개념은

**“AI 스터디 메이트들과 한 공간에서 함께 공부한다.”**

이다.

따라서 첫 화면에서 가장 먼저 보여줘야 할 것은 AI가 대답하는 모습이 아니라

**AI 캐릭터들이 사용자와 같은 스터디룸 안에 존재하고 있다는 모습**이다.

사용자는 이 화면을 통해

> 내가 공부할 때 항상 함께 공부하는 AI 스터디 그룹이 있다.

라는 느낌을 받을 수 있어야 한다.

---

# 15. 디자인 우선순위

구현할 때 다음 우선순위를 지켜줘.

**1순위 — 한눈에 이해되는 구조**

왼쪽의 AI 스터디룸과 오른쪽의 Alongside 브랜드 영역이 명확하게 구분되어야 한다.

**2순위 — 캐릭터 존재감**

왼쪽의 네 캐릭터가 단순한 장식물이 아니라 실제 스터디원처럼 느껴져야 한다.

**3순위 — 충분한 여백**

요소를 많이 넣지 않고 편안한 첫 화면을 만든다.

**4순위 — 브랜드 가독성**

Alongside라는 이름이 분명하게 기억될 수 있어야 한다.

**5순위 — 명확한 진입 동선**

사용자가 페이지를 본 뒤 바로 Sign Up 또는 Sign In을 선택할 수 있어야 하며, 버튼 클릭 후 별도 페이지 이동 없이 Google 로그인 modal로 자연스럽게 이어져야 한다.

---

# 16. 최종 페이지 구성

최종적으로 첫 화면에는 **오직 다음 핵심 요소들만 있으면 된다.**

### 왼쪽

**4명의 AI 캐릭터가 함께 공부하고 있는 2 × 2 스터디룸**

### 오른쪽

**Alongside**

**Study alongside AI companions who keep you focused.**

**Sign Up / Sign In**

두 버튼을 클릭하면 동일한 **Google 로그인 modal**이 열린다.

modal의 핵심 구성은 다음과 같다.

- Alongside
- 짧은 안내 문구
- Continue with Google
- 닫기 버튼
- Terms / Privacy

불필요한 설명, 기능 목록, 긴 소개 문구 등은 첫 화면에 추가하지 않는다.

목표는 **아주 단순한 구조만으로 Alongside라는 서비스의 컨셉을 전달하는 것**이다.
